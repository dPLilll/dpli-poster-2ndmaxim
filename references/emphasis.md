# 强调文字（放大词）

> 本文件内容迁移自原 SKILL.md 的同名章节，规则未删改；SKILL.md 中的硬约束与此处一致，冲突时以更严格者为准。

## 强调文字

- 文字确认前先理解句意、转折、意象和关键对比，选出适合放大的核心词组。用户明确指定的强调词优先；未指定时可主动提出少量准确词组，不必每句都强调。
- 确认稿正文按实际断行展示，不插入强调标记。正文下方写“放大词（海报中为普通字的 1.55 倍）：”，再用 Markdown 三级标题单列词组，例如 `### 高薪 · 高职 · 高级品`，让放大词醒目可辨。没有强调时写“放大词：无”。标题展示用于确认，不是海报排版预览；标签、分隔点和标题符号均不写入正文或图片。用户可以修改或取消，确认后才把准确词组写入 `emphasis`。
- 按默认简体转换保留字词含义和顺序。大字小字可以同排，强调词不强制独占行，也不增加空行。放大比例为普通正文的 1.55 倍，固定像素字距不变。行距按小字的视觉节奏安排，强调大字按实际位置协调，不单独推开前后行，也不触发自动放大全局行距。
- 多个语义相关的强调词可以集中排成一个连续的大字块，避免不必要地分散在小字中。当行长、词组与原文顺序允许时，可让强调词位于各自行的开头（行首），形成清楚的阅读入口；这里不是指必须放在整张正文第一行。行首与集中分组均为优先比较的可选排法，不强制所有作品采用。可比较大字独占一行、连续两行或大小字混排等方案；这些是可选手法，不固定每张都采用。分组不改变原文字词及先后顺序；最终方案仍先展示文字确认稿。
- 新海报按本次语义和用户要求选择强调，不继承上一张的强调词；同张修改保留已确认强调，除非用户更改。用户要求不强调时用空列表。整体放大填满区域不属于局部强调。
