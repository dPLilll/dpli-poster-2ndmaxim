# 项目目录、文件命名与 HTML 共享素材

> 本文件内容迁移自原 SKILL.md 的同名章节，规则未删改；SKILL.md 中的硬约束与此处一致，冲突时以更严格者为准。

## 项目目录与文件命名

- 按任务或作品建立一个项目目录，如 `陈奕迅陀飞轮/`。同一任务的多张海报放在同一个 `成品/` 目录，配置集中在 `配置/`，旧版本归入 `历史版本/`。不为每张图单独建目录，也不把同一任务的修改版散放在项目根目录。
- 多张图片用编号和内容短名区分，例如 `03_秒速捉得紧了.png`。配置可指定 `outputName`，渲染器会在同一输出目录保存同名 PNG、HTML 与 `<outputName>_排版参数.json`。
- 整理时保留用户素材、原始下载文件与旧版本，避免覆盖不属于本任务的文件。

## HTML 体积与共享素材

- 默认 HTML 使用相对路径引用同一成品目录下的 `_assets/` 共享素材，不把完整字体或图片以 Base64 重复内嵌到每个 HTML。
- 字体、底纹、Logo 及相同照片或颗粒按内容复用，多个海报共用一份相同素材；不同素材保留独立文件，不覆盖其他海报正在引用的素材。
- HTML 保持 SVG 文字和 CSS 图层可编辑。移动、备份或分享时保留 HTML 与 `_assets/` 的相对位置，打包整个成品目录；PNG 独立使用，不依赖该目录。
- 不以单文件离线打开为默认目标而重复存储大字体。用户明确要求自包含 HTML 时才另行评估字体子集等方案，并说明体积代价。

## 共享字体目录（sharedFontDir，可选）

- 默认行为不变：字体与图片按内容哈希复制到 `成品/_assets/`（两款完整字体约 60 MB），整个成品目录可直接打包分享。
- 多个任务反复出图、本机磁盘占用是问题时，可在配置中设 `sharedFontDir`（相对配置文件的路径，例如 `"../../_fonts"`）。渲染器把**原样、逐字节相同**的字体文件只保存一份到该目录的 `_assets/`，HTML 用相对路径引用；成品目录只剩约 1–2 MB。
- 字体授权禁止修改字体文件或传播修改版：不得对又又意宋、京華老宋体做子集化、格式转换（woff/woff2）或任何改写；`sharedFontDir` 只是换存放位置，不改字体。
- 使用 `sharedFontDir` 时，分享可编辑 HTML 必须连同共享字体目录一起打包并保持相对位置；只分享 PNG 不受影响。用户要求“单独发一个可编辑文件夹”时，不设 `sharedFontDir`。
